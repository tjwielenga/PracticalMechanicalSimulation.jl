Planar Modeler User's Guide

This directory contains the user documentation for the supported two-dimensional modeling program. It does not describe a spatial modeler.

Using the planar modeling program

  1. Start with the project overview and run one supplied model.
  2. Follow Using the Planar Modeler for a complete run, view, export, and restart workflow.
  3. Use the TOML User's Guide while building or editing a mechanism.
  4. Read the result-file description for HDF5 storage, viewing, CSV conversion, and model extraction.
  5. Use Sim2D Lua Assemblies to package calculated or hierarchical constructions for reuse.
  6. Use the Sim2D Julia model-building API to construct models directly in Julia, and the Julia library API for loading, running, and processing existing models.
  7. Read Sparse modal linear analysis for operating-point linearization, the descriptor eigenproblem, and modal result storage.

The maintained TOML and Lua models are in models/planar. Their companion explanations include:

  • constant-speed slider-crank, a kinematic slider crank mechanism;
  • torque-driven four-bar, a four bar mechanism driven by a torque on the driver link;
  • planar bushing, an example of using a bushing;
  • relative-coordinate pendulum

demonstrates making a revolute-owned angle the preferred state;

  • bushing-supported pendulum replaces a revolute

joint with a bushing;

  • constant-speed external gear pair

introduces generated floating markers and an ideal gear-pair constraint.

  • internal gear pair

demonstrates an internal gear set;

  • planetary gear set demonstrates

how a moving carrier can produce a planetary gear set;

  • constant-speed rack and pinion

couples a translational joint to a revolute joint;

  • three-pulley belt models a three pulley

system with elastic tangent spans and a spring-loaded tensioner;

  • perp-guided slider combines the

inplane and perp primitives to make a prismatic guide;

  • translational-joint slider

uses the corresponding user-facing one-freedom joint;

  • translational-distance slider

adds a one-direction prescribed distance, velocity, acceleration, and reaction force;

  • rotational-coordinate-coupler.toml

couples two revolute joints together;

  • translational-coordinate-coupler.toml

couples measured distance ports;

  • screw-motion-coupler.toml couples a rotation to a translation;
  • fixed-joint rotating assembly

shows a convenience joint assembled from revolute and perp primitives;

  • spanning-spring pendulum uses the

spanning force element;

  • nonlinear spanning-force pendulum

uses a spanning force with an expression based on its length and length rate;

  • distance-measures.toml model

shows reaction-free straight-line and directed-distance measurements and their viewer symbols;

  • torsional-spring pendulum uses a

rotational spring-damper and displays its explicit torque;

  • nonlinear expression pendulum

uses a revolute angle and angular velocity in a user-written constitutive torque law;

  • PID-controlled pendulum

adds an integral state and algebraic control variables to the mechanism's implicit system with a user-defined equation component.

  • bouncing ball demonstrates compliant

one-sided contact and BDF history restart at force-law transitions;

  • rotating cam and follower

uses a cubic profile cam and a circular roller with a damped normal force;

  • rotating cam and flat follower

uses a cubic profile cam a flat plate with moving contact point;

  • rocker follower

cam with rocking flat plate follower;

  • rocker roller follower

cam with rocking roller follower;

  • planar friction examples

demonstrate one-sided surface friction, revolute bearing friction, translational guide friction, and bilateral inplane friction through sliding, sticking, separation behavior, and breakaway;

  • stage-dependent force example

uses static-only supports that are removed automatically when dynamics begins;

  • flexible-cantilever.toml

and rectangular-flexible-cantilever.toml show explicit and section-derived floating-reference flexible beams;

  • modal-pendulum.toml model provides the

small analytical reference case for modal linear analysis.

The executables:

  • julia_api_double_pendulum.jl

demonstrates reusable nested Sim2D assembly functions and the resulting model and SimpView hierarchy;

  • lua-double-pendulum.lua

constructs the same kind of hierarchy from a reusable Lua assembly module.

Related material

The planar Technical Manual explains the implementation and equations. Shared integration, state-selection, result-file, and modal methods are in the common Technical Manual. The separate paper workspace retains the analysis studies and evidence used for the Fully Consistent methods paper.
