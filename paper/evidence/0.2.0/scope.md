# Evidence scope for v0.2.0

The CSV files in this directory are new measurements of the released 0.2.0 simulation program.

The following comparisons are intentionally not regenerated:

- Table 20's generic sparse LU, first UMFPACK, and symbolic-only rows describe earlier implementations. The open-chain CSV supplies the current final implementation.
- Table 25's hard-restart rows describe the former restart policy. Version 0.2.0 uses the soft restart; the CSV measures it.
- Table 26's ordinary-array and first fixed-size rows describe earlier implementations. `large_van.csv` supplies the current final row.

Table 27 is a separate full-length engineering demonstration rather than an
implementation microbenchmark. `large_van_10s_maneuver.csv` contains its
unrounded version 0.2.0 measurements.

Tables 3--5 are regenerated by `formulation_evidence.jl` in the isolated
`test/paper` environment because they compare historical formulations rather
than the supported model runner. Their values are stored in the three
`formulation_*.csv` files.
